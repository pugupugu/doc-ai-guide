# 문서 종류별 질문 목록

질문 순서대로 묻는다. 필수(★)는 반드시 답을 받고, 나머지는 건너뛸 수 있다. 선택지가 있으면 선택지로 보여 준다.

## ppt — 파워포인트 (보고서, 제안서, 발표 자료)
- 최종 결과물 형식: .pptx 파일. 파일을 만들 수 없다면 장마다 제목, 본문, 시각 자료(차트·표·이미지) 지시, 발표자 노트를 정리해 줘.

### 기본 정보
- ★ **문서 제목** (id: title, 프롬프트 표기: 문서 제목, 영역: purpose) — 예) 3분기 실적 보고
- ★ **이 문서로 이루고 싶은 것** (id: purpose, 프롬프트 표기: 목적, 영역: purpose) — 예) 임원진에게 3분기 성과를 보고하고 4분기 예산 승인을 받는다
- **배경 설명** (id: background, 프롬프트 표기: 배경, 영역: purpose) — 예) 신규 고객이 늘어 매출이 12% 성장했다 / 도움말: AI가 상황을 이해할 수 있게 짧게 적어 주세요.
- ★ **읽는 사람 (받는 사람)** (id: audience, 프롬프트 표기: 대상, 영역: audience) — 예) 임원진, 팀 전체, 고객사 담당자
- **읽는 사람이 이 내용을 얼마나 알고 있나요?** (id: audience_level, 프롬프트 표기: 대상의 이해 수준, 영역: audience) [선택지: 처음 접함 / 대략 알고 있음 / 잘 알고 있음 (전문가)]

### 내용
- ★ **몇 장 정도로 만들까요?** (id: slide_count, 프롬프트 표기: 장수, 영역: content) — 10 / 도움말: 발표 10분 기준 약 8~10장이에요.
- **발표 시간** (id: duration, 프롬프트 표기: 발표 시간, 영역: content) — 예) 10분
- ★ **장별 구성** (id: structure, 프롬프트 표기: 장별 구성, 영역: content) — 예) 1장 표지 / 2장 요약 / 3~5장 실적 / 6장 다음 계획 / 도움말: 모르면 큰 흐름만 적어도 돼요. AI가 나머지를 채워요.
- **가장 전하고 싶은 한 마디** (id: key_message, 프롬프트 표기: 핵심 메시지, 영역: content) — 예) 3분기는 목표를 넘었고, 4분기엔 신규 시장에 집중한다
- **꼭 들어갈 숫자·데이터** (id: numbers, 프롬프트 표기: 꼭 들어갈 숫자·데이터, 영역: content) — 예) 매출 120억(전년 대비 +12%), 신규 고객 35곳

### 디자인·형식
- **디자인 분위기** (id: mood, 프롬프트 표기: 디자인 분위기, 영역: design) [선택지: 깔끔한 비즈니스 / 따뜻하고 친근한 / 강렬하고 임팩트 있는 / 미니멀]
- **쓰고 싶은 색** (id: colors, 프롬프트 표기: 쓰고 싶은 색, 영역: design) — 예) 남색과 주황 포인트
- **넣고 싶은 시각 자료** (id: visuals, 프롬프트 표기: 넣고 싶은 시각 자료, 영역: design) [선택지: 막대 차트 / 꺾은선 차트 / 원형 차트 / 표 / 아이콘 / 사진 (여러 개 가능)]
- **글 말투** (id: tone, 프롬프트 표기: 글 말투, 영역: design) [선택지: 격식체 (~합니다) / 개조식 (~함) / 부드러운 존댓말 / 친근한 말투]
- **화면 비율** (id: ratio, 프롬프트 표기: 화면 비율, 영역: design) [선택지: 16:9 (와이드) / 4:3]

### 첨부자료
- 첨부 파일이 있는지 묻고, 있으면 파일마다 '사용 방법'(예: 표지 이미지로 사용, 이 표의 숫자 활용)을 받는다. 파일 내용은 `첨부자료/`에 그대로 복사한다.

### 기타 요청
- **꼭 지켜야 할 것** (id: must_include, 프롬프트 표기: 꼭 지켜야 할 것, 영역: rules) — 예) 회사 이름은 '인크로스'로 표기, 숫자는 억 단위
- **피해야 할 것** (id: avoid, 프롬프트 표기: 피해야 할 것, 영역: rules) — 예) 과장된 표현, 영어 약어 남발
- **그 밖에 하고 싶은 말** (id: extra, 프롬프트 표기: 그 밖에 하고 싶은 말, 영역: rules) — 예) 초안을 2가지 버전으로 만들어 줘

## excel — 엑셀 (데이터 정리, 예산표, 일정표)

### 기본 정보

- **읽는 사람이 이 내용을 얼마나 알고 있나요?** (id: audience_level, 프롬프트 표기: 대상의 이해 수준, 영역: audience) [선택지: 처음 접함 / 대략 알고 있음 / 잘 알고 있음 (전문가)]

### 내용
- ★ **시트 구성** (id: sheets, 프롬프트 표기: 시트 구성, 영역: content) — 예) 1. 월별 예산 / 2. 부서별 합계 / 3. 차트
- ★ **열(항목) 목록** (id: columns, 프롬프트 표기: 열(항목) 목록, 영역: content) — 예) 월, 부서, 항목, 예산, 실제 사용액, 차이
- **필요한 계산** (id: formulas, 프롬프트 표기: 필요한 계산, 영역: content) — 예) 차이 = 예산 - 실제 사용액, 사용률(%)
- **합계** (id: totals, 프롬프트 표기: 합계, 영역: content) [선택지: 합계만 / 소계와 합계 / 필요 없음]
- **예시 데이터 줄 수** (id: sample_rows, 프롬프트 표기: 예시 데이터 줄 수, 영역: content) — 10 / 도움말: 빈 양식만 원하면 0으로 적어 주세요.

### 디자인·형식
- **넣을 기능** (id: features, 프롬프트 표기: 넣을 기능, 영역: design) [선택지: 첫 줄 고정 / 필터 / 드롭다운 선택칸 / 인쇄 영역 설정 / 시트 보호 (여러 개 가능)]
- **색으로 강조할 조건** (id: conditional, 프롬프트 표기: 색으로 강조할 조건, 영역: design) — 예) 사용률 100% 넘으면 빨간색
- **넣고 싶은 차트** (id: charts, 프롬프트 표기: 넣고 싶은 차트, 영역: design) [선택지: 막대 차트 / 꺾은선 차트 / 원형 차트 / 필요 없음 (여러 개 가능)]
- **숫자 표시 방식** (id: number_format, 프롬프트 표기: 숫자 표시 방식, 영역: design) — 예) 천 단위 쉼표, 원 단위

## email — 이메일 (업무 메일, 안내 메일)
